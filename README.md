# Hitry Slon — клиентская сборка

Публичная витрина модпака Minecraft с Create Aeronautics.
Готовые сборки будут доступны в [Releases](https://github.com/hitry-slon/client/releases).
Сейчас релизов ещё нет.

Исходники сборки и инфраструктура хранятся в приватном репозитории `server`.
Здесь публикуются только клиентские артефакты, инструкция и история изменений.

Планируемый формат — `.mrpack` для импорта в совместимый лаунчер
(например, Modrinth App или Prism Launcher). При импорте лаунчер скачивает
закреплённые версии модов. Версия клиента должна совпадать с версией сервера.
Minecraft 1.21.1 / NeoForge / Java 21.

Клиентские артефакты не содержат секретов и серверных инструментов аудита.
Установка кастомных модов автоматическая, вместе с выпуском сборки.
