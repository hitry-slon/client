# Hitry Slon — клиентская сборка

Публичная витрина модпака Minecraft с Create Aeronautics.
Готовые сборки публикуются в [Releases](https://github.com/hitry-slon/client/releases).
На 17 ноября 2026 первый релиз ещё не создан.

## Установка

1. Выберите релиз той версии, которую использует сервер.
2. Скачайте asset hitry-slon.mrpack.
3. Импортируйте его в совместимый лаунчер, например Modrinth App или Prism Launcher.
4. Дождитесь скачивания модов и запускайте созданный профиль.

Платформа сборки — Minecraft 1.21.1, NeoForge, Java 21. Точные версии
записаны внутри архива и в release.json рядом с ним. .mrpack содержит
закреплённые ссылки/хеши: моды скачиваются при импорте, поэтому нужен интернет.
Произвольное обновление отдельных модов может нарушить совместимость с сервером.

## Что хранится здесь

- Инструкция для игроков.
- CI проверки клиентского артефакта и создания GitHub Release.
- После выпуска — release/hitry-slon.mrpack и release/release.json.

Исходники модпака и инфраструктура находятся в приватном server. Его CI
передаёт сюда готовую сборку после выпуска версии; собственный CI этого
репозитория проверяет архив и публикует assets. Уже созданные Releases
автоматически не перезаписываются.

release.json содержит версию, SHA исходного commit, SHA256 архива и версии
платформы. В клиент не входят серверные инструменты аудита, серверные конфиги
и секреты. Подключение будущих собственных модов mod-* будет реализовано
отдельно; сейчас не требуется скачивать дополнительные JAR из таких репозиториев.
